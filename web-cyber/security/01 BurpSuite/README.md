# 01 BurpSuite

Une fois Burp Suite installe, ouvrez la [Web Security Academy](https://portswigger.net/web-security). Dans la section **Learning materials and labs**, cliquez sur **View all labs**, puis choisissez un theme et un exercice adaptes a votre niveau. Ouvrez le lab et cliquez sur **Access the lab** : l'application cible est fournie par PortSwigger.

Configurez votre navigateur pour utiliser le proxy de Burp Suite, puis utilisez notamment **Proxy** et **Repeater** pour observer et rejouer les requetes. Travaillez uniquement sur les labs fournis par la plateforme.

Si vous etes bloque, revenez a la page de l'exercice et ouvrez **View solution**. La solution proposee inclut la video de reponse pour suivre la demonstration, comprendre les etapes, puis refaire le lab vous-meme. Creez un compte PortSwigger si vous souhaitez enregistrer votre progression.
