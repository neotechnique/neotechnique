# Ateliers web et cybersecurite

Ce repertoire contient deux ateliers distincts :

- **Defense** : developper puis publier un site web sur [Neocities](https://neocities.org/).
- **Attaque** : apprendre les techniques de base pour casser des sites web.

Chaque atelier dispose de son propre flocon Nix. Placez-vous dans le repertoire
de l'atelier souhaite, puis activez son environnement avec :

```sh
nix develop
```
